# 🌐 Minha Primeira Landing Page com HTML e CSS

Este projeto é uma **landing page desenvolvida exclusivamente com HTML e CSS**, criada como parte da **Trilha de CSS da DIO (Digital Innovation One)**.  
O objetivo é praticar fundamentos de estruturação com HTML e estilização com CSS, sem o uso de bibliotecas ou frameworks externos.

---

## 🧠 O que foi aprendido

Durante o desenvolvimento deste projeto, foram aplicados conceitos essenciais como:

- Estrutura semântica com **HTML5**
- Estilização com **CSS3**
- Uso de:
  - Gradientes
  - Backgrounds com imagem
  - Posicionamento e centralização de elementos
  - Bordas, sombras e efeitos visuais
- Boas práticas de organização de código
- Responsabilidade visual básica (viewport configurada)

---

## 🎨 Layout da Página

A landing page é composta por:

- **Banner principal** com chamada para ação
- **Seção de conteúdo do curso** com lista de módulos
- **Seção com efeito parallax** (`background-attachment: fixed`)
- **Seção de desafios profissionais**
- **Rodapé institucional**

Todo o layout foi desenvolvido sem frameworks, utilizando apenas CSS puro.

---

- HTML5  
- CSS3
