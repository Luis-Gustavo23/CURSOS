# 🌐 Primeiros Passos com HTML - 1

Este projeto é um arquivo HTML simples criado para aprender os conceitos básicos de HTML.

## 🎯 Objetivo do Projeto

Ensinar os fundamentos do HTML para iniciantes, mostrando na prática como estruturar uma página web.

## 🧱 Conteúdo do Projeto

### 📌 Estrutura Básica do HTML
- Uso das tags html, head e body
- Definição de título e codificação da página

### 📝 Textos e Formatação
- Títulos (h1 até h6)
- Parágrafos
- Negrito, itálico, sublinhado e marcação de texto

### 📋 Listas e Links
- Listas não ordenadas
- Links internos e externos

### 🧾 Formulários
- Campos de texto, número, email e senha
- Uso das tags form, input, label e button

### 🖼️ Mídias
- Imagens
- Vídeos
- Áudios
- iframe

### 📊 Tabelas
- Linhas e colunas
- Cabeçalhos e rodapé da tabela

### 🧠 HTML Semântico
- header
- nav
- main
- section
- footer

## 🧭 Navegação

O projeto possui um índice no topo da página, permitindo navegar entre os conteúdos por meio de links internos.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS básico
