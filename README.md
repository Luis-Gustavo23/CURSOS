# 📚 Meus Cursos

Repositório com projetos, exercícios e experimentos desenvolvidos durante minha jornada de aprendizado em desenvolvimento web e lógica de programação.

## 📁 Projetos

### HTML

- [Meu Primeiro HTML](./Meu-Primeiro-HTML/) - Página introdutória para praticar a estrutura básica do HTML, textos, listas, links, formulários, mídias, tabelas e elementos semânticos.
- [Meu Segundo HTML](./Meu-Segundo-HTML/) - Artigo enciclopédico sobre Genshin Impact, inspirado na Wikipedia, com navegação interna, sidebar, conteúdo multimídia e foco em semântica e acessibilidade.
- [Meu Terceiro HTML](./Meu-Terceiro-HTML/) - Site com múltiplas páginas: página inicial, sobre, serviços e contato.

### HTML e CSS

- [Minha Primeira Landing Page](./Minha-Primeira-Landing-Page-com-HTML-e-CSS/) - Landing page da Trilha de CSS da DIO, com banner, módulos do curso, parallax, desafios profissionais e rodapé.
- [Minha Segunda Landing Page](./Minha-Segunda-Landing-Page-com-HTML-e-CSS/) - Landing page de planos de hospedagem com três opções de assinatura: Essencial, Premium e Gold.
- [Minha Terceira Landing Page](./Minha-Terceira-Landing-Page-com-HTML-e-CSS/) - Landing page clássica com menu horizontal, banner, artigos, links e rodapé.

### JavaScript

- [Classificador de Nível de Herói](./Classificador-de-Nivel-de-Heroi/) - Programa que classifica o nível de um herói de acordo com a quantidade de XP informada, praticando variáveis, comparações e estruturas condicionais.

## 🎯 Objetivos

- Acompanhar minha evolução na programação;
- Revisar conceitos aprendidos nos cursos;
- Praticar a criação de páginas web e layouts;
- Desenvolver uma base para projetos maiores e um portfólio.

## 🛠️ Tecnologias e Conceitos

- HTML5 e elementos semânticos;
- CSS3, Flexbox, backgrounds, gradientes, parallax e responsividade;
- JavaScript e lógica de programação;
- Acessibilidade, navegação interna e organização de arquivos;
- Separação entre estrutura, estilo e comportamento.

## 🚀 Como Executar

Os projetos são estáticos e não precisam de instalação de dependências.

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto desejado.
3. Abra o arquivo `index.html` diretamente no navegador ou use a extensão **Live Server** do VS Code.

Para executar o classificador, abra um terminal na pasta [Classificador-de-Nivel-de-Heroi](./Classificador-de-Nivel-de-Heroi/) e rode:

```bash
node Classificador.js
```
