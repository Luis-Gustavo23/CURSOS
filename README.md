# 📚 Meus Cursos

Bem-vindo ao meu repositório de cursos! 🎓

Este é um espaço dedicado a documentar minha jornada de aprendizado contínuo. Aqui você encontrará todos os projetos, exercícios e exemplos práticos que desenvolvo ao longo dos cursos que realizo.

## 📁 Estrutura do Repositório

O repositório está organizado por cursos e temas, cada um com seus próprios arquivos e recursos:

- **Meu-Primeiro-HTML** - Primeiros passos com HTML
- **Meu-Segundo-HTML** - Estruturação com CSS e organização de arquivos
- **Meu-Terceiro-HTML** - Projetos mais avançados com múltiplas páginas

## 🎯 Objetivo

Usar este repositório para:
- Acompanhar meu progresso na programação
- Revisar conceitos aprendidos
- Compartilhar conhecimento e projetos
- Construir um portfólio de desenvolvimento

## 🚀 Como Usar

Cada pasta contém um projeto ou exercício relacionado ao curso correspondente. Dentro de cada pasta você encontrará:
- Arquivos de código-fonte (HTML, CSS, JavaScript)
- README específico do projeto (quando aplicável)
- Recursos adicionais (imagens, fontes, etc.)

## 💡 Tecnologias

Os projetos utilizam:
- HTML5
- CSS3
- JavaScript (quando aplicável)
- E outras tecnologias conforme os cursos progridem
