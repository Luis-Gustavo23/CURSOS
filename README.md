## 🚀 Como Usar

Cada pasta contém um projeto ou exercício relacionado ao curso correspondente. Dentro de cada pasta você encontrará:
- Arquivos de código-fonte (HTML, CSS, JavaScript, etc.)
- README específico do projeto (quando aplicável)
- Recursos adicionais (imagens, fontes, dados de exemplo, etc.)

### Como rodar os projetos localmente

1. Clone o repositório:

   git clone https://github.com/Luis-Gustavo23/CURSOS.git

2. Entre na pasta do projeto desejado:

   cd CURSOS/Nome-do-projeto

3. Siga as instruções do README específico do projeto. Para projetos com Node.js:

   npm install
   npm start

Para projetos estáticos, basta abrir o arquivo `index.html` no navegador ou usar um servidor local como o Live Server do VS Code.

## 🤝 Como Contribuir

Contribuições são bem-vindas! Algumas formas de contribuir:
- Abrir issues relatando bugs ou sugerindo melhorias
- Enviar pull requests com correções, novos exercícios ou atualizações de conteúdo
- Sugerir novos cursos ou recursos nos issues

Fluxo recomendado:
1. Fork do repositório
2. Crie uma branch com um nome descritivo: `feature/nome-da-feature` ou `fix/descricao-curta`
3. Faça commits claros e pequenos
4. Abra um Pull Request descrevendo a mudança
