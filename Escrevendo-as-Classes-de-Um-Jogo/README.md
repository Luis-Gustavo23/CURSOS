# ⚔️ Escrevendo as Classes de um Jogo

## 📖 Descrição

Este projeto foi desenvolvido para praticar a criação e utilização de classes em **JavaScript**.

O programa representa um herói de jogo por meio da classe `Heroi` e exibe o tipo de ataque que ele realiza de acordo com sua classe.

---

## 🎯 Objetivo

Criar uma classe que receba as seguintes informações:

- Nome do herói
- Idade do herói
- Tipo do herói

O método `atacar()` identifica o tipo do herói e define o ataque utilizado:

| Tipo | Ataque |
|---|---|
| Mago | Magia |
| Guerreiro | Espada |
| Monge | Artes marciais |
| Ninja | Shuriken |

---

## 🚀 Como executar

Com o **Node.js** instalado, execute no terminal:

```bash
node classesJogo.js
```

No exemplo presente no código, o herói é um mago chamado Gustavo Rodrigues, de 24 anos. O resultado exibido é:

```text
o mago atacou usando magia
```

---

## 🧩 Estrutura do projeto

- `classesJogo.js`: define a classe `Heroi`, cria uma instância e exibe seu ataque no console.

---

## 📚 Conceitos praticados

- Classes e construtores
