# 🌐 Primeiros Passos com HTML - 2

Este projeto tem como objetivo recriar a proposta da **Wikipedia**, aplicando um **layout mais moderno**, organizado e visualmente agradável, sem perder o foco principal: **conteúdo bem estruturado, semântico e acessível**.

A página utiliza como tema o jogo **Genshin Impact**, apresentando informações organizadas em seções, links externos relevantes, vídeos incorporados e navegação interna, simulando a experiência de leitura de um artigo enciclopédico — porém com uma abordagem visual mais atual.

---

## 🎯 Objetivo do Projeto

- Reproduzir a ideia central da Wikipedia (artigos informativos)
- Melhorar a experiência do usuário com um layout mais moderno
- Aplicar corretamente **HTML semântico**
- Garantir **acessibilidade** para diferentes tipos de usuários
- Praticar estruturação de páginas web utilizando apenas HTML e CSS

---

## 🧱 Estrutura do Projeto

O projeto é composto por:

- **Header** com logotipo
- **Barra visual** para separação estética
- **Menu lateral (sidebar)** com links externos
- **Conteúdo principal (article)** com várias seções temáticas
- **Navegação interna (anchors)** para facilitar o acesso às seções
- **Footer** com informações legais e autoria

Estrutura de pastas:

```text
assets/
├── css/
│ └── style.css
├── images/
│ └── Genshin Impact Logo.png
index.html
```

## 🧩 Semântica HTML

O projeto faz uso de **tags semânticas do HTML5**, que ajudam navegadores, mecanismos de busca e tecnologias assistivas a compreenderem melhor a estrutura da página.

Principais elementos semânticos utilizados:

- `<header>`: cabeçalho da página
- `<main>`: conteúdo principal
- `<nav>`: menus de navegação (links externos e navegação interna)
- `<article>`: conteúdo principal do artigo
- `<section>`: divisão temática do conteúdo
- `<figure>` e `<figcaption>`: vídeos e suas descrições
- `<footer>`: rodapé com informações finais

O uso correto dessas tags melhora:

- SEO (otimização para mecanismos de busca)
- Organização do código
- Manutenção e legibilidade

---

## ♿ Acessibilidade

A acessibilidade foi considerada desde a estrutura do HTML, garantindo que o site possa ser utilizado por pessoas com diferentes necessidades.

Recursos aplicados:

- Atributo `lang="pt-br"` para leitores de tela
- Textos alternativos (`alt`) em imagens
- Uso de `aria-label` em elementos de navegação
- Estrutura hierárquica correta de títulos (`h1` a `h2`)
- Links claros e descritivos
- Navegação interna por âncoras

Essas práticas tornam o site mais inclusivo e compatível com tecnologias assistivas.
