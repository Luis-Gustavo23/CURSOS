# Minha Terceira Landing Page com HTML e CSS

Este projeto é uma landing page construída usando **HTML** e **CSS**, sem o uso de frameworks ou Flexbox. O objetivo é praticar a estruturação semântica de páginas, organização de CSS e criação de layouts clássicos.

---

## 🔹 Funcionalidades

- Menu de navegação horizontal
- Banner com imagem de fundo
- Seção de artigos com títulos e links
- Footer estilizado
- Layout limpo e organizado, fácil de entender

---

## 🔹 Tecnologias Utilizadas

- HTML5
- CSS3

---

## 📚 Aprendizados com este projeto

- Organização de CSS por escopo e hierarquia  
- Estrutura semântica correta de uma landing page  
- Estilização de menus horizontais clássicos  
- Uso de backgrounds, cores e tipografia para design visual
