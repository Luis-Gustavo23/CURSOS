# 🌐 Minha Segunda Landing Page com HTML e CSS

Este projeto é uma **landing page de planos de hospedagem**, desenvolvida utilizando apenas **HTML5 e CSS3**.  

O objetivo foi praticar estruturação semântica, organização de layout com **Flexbox** e boas práticas de estilização.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Flexbox

---

## 📋 Funcionalidades

- Estrutura semântica com `header`, `nav`, `main` e `article`
- Layout organizado com Flexbox
- Cards de planos estilizados
- Botões de ação
- Design moderno com cores contrastantes

---

## 🎯 Objetivo do Projeto

- Praticar HTML semântico  
- Aprender organização de layout com Flexbox  
- Melhorar estrutura e organização de CSS  
- Desenvolver base sólida para projetos maiores  

---

## 📸 Preview

Landing page com três planos:

- Essencial  
- Premium  
- Gold  

Cada plano possui:

- Nome  
- Preço  
- Lista de benefícios  
- Botão de assinatura  

---

## 💡 Aprendizados

Durante o desenvolvimento deste projeto, foram reforçados conceitos como:

- Hierarquia de títulos  
- Organização visual com Flexbox  
- Separação de responsabilidades (HTML e CSS)  
- Estilização de listas e pseudo-elementos  
- Estruturação de componentes reutilizáveis
