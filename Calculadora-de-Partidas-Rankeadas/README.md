# 🏆 Calculadora de Partidas Rankeadas

## 📖 Descrição

Este projeto foi desenvolvido para praticar conceitos básicos de lógica de programação utilizando **JavaScript**.

O programa calcula o saldo de vitórias de um herói e classifica seu nível com base nesse saldo.

---

## 🎯 Objetivo

Calcular o saldo de partidas ranqueadas usando a fórmula:

```text
saldo de vitórias = vitórias - derrotas
```

Depois, o saldo é utilizado para definir o nível do herói:

| Saldo de vitórias | Nível |
|---|---|
| Menor ou igual a 10 | Ferro |
| 11 – 20 | Bronze |
| 21 – 50 | Prata |
| 51 – 80 | Ouro |
| 81 – 90 | Diamante |
| 91 – 100 | Lendário |
| Maior que 100 | Imortal |

---

## 🚀 Como executar

Com o **Node.js** instalado, execute no terminal:

```bash
node calculadora.js
```

No exemplo presente no código, o herói possui 15 vitórias e 4 derrotas. O resultado é um saldo de 11 vitórias e nível **Bronze**.

---

## 🧩 Estrutura do projeto

- `calculadora.js`: calcula o saldo, classifica o nível e exibe o resultado no console.
