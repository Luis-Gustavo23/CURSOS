# 🏆 Classificador de Nível de Herói

## 📖 Descrição

Este projeto foi desenvolvido com o objetivo de praticar conceitos básicos de lógica de programação utilizando **JavaScript**.

O programa classifica o nível de um herói com base na quantidade de experiência (XP) informada.

---

## 🎯 Objetivo

Criar uma variável para armazenar:

- O nome do herói
- A quantidade de experiência (XP)

E utilizar uma estrutura de decisão (`if / else if / else`) para determinar o nível do herói com base na seguinte tabela:

| XP | Nível |
|----|-------|
| Menor ou igual a 1.000 | Ferro |
| 1.001 – 2.000 | Bronze |
| 2.001 – 5.000 | Prata |
| 5.001 – 7.000 | Ouro |
| 7.001 – 8.000 | Platina |
| 8.001 – 9.000 | Ascendente |
| 9.001 – 10.000 | Imortal |
| Maior ou igual a 10.001 | Radiante |
